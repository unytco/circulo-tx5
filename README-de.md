## Ein spielerischer Blick auf P2P-Zahlungen

<div align="left">
<h3>

</h3>
<h3> Einführung

Willkommen zu Version 3 von Circulo!

Circulo ist ein auf Großzügigkeit basierendes Peer-to-Peer-Zahlungssystem, das auf der Unyt-Technologie für gegenseitige Kreditvergabe basiert.

Jeder startet mit einem Kontostand von null und einem kleinen Kreditlimit. Dieses Kreditlimit bestimmt den maximalen Betrag, den Sie ausgeben können.

Circulo verwendet einen sehr einfachen Kreditalgorithmus: Jedes Mal, wenn Sie jemandem Einheiten senden, erhöht sich Ihr Kreditlimit ein wenig. Dieser einfache Algorithmus ist leicht zu manipulieren und lädt daher zum Ausnutzen ein.

In Circulo wird Ihr Konto sofort belastet, sobald Sie jemandem Einheiten senden. Der Kontostand des Empfängers enthält diese Einheiten jedoch erst, nachdem dieser sie angenommen hat. Wenn sie die Gutscheine nicht annehmen, bleiben sie für die Teilnehmer verfügbar. Niemand sonst kann sie beanspruchen.


Durch die Verankerung der Aktivitäten in der Eigenverantwortung der Teilnehmer eröffnet Circulo interessante neue Effizienzgewinne und Möglichkeiten. Diese werden in zukünftigen Versionen detaillierter untersucht.


Weitere Informationen zu Circulo3 finden Sie im <a href="https://unyt.co/blog/circulo3/">Blogbeitrag zu Circulo3</a> – nicht nur zu dieser Version, sondern auch zur Rolle von Circulo bei der Verbesserung von Unyt und Holochain im Allgemeinen.

</p>
<img src="docs/images/Switch-languages-in-Circulo3.png" alt="Sprachenwechsel in Circulo3" width="100%" style="max-width: 800px; height: auto;">

<h3>
Testen

</h3>
<p>
Diese dritte Version von Circulo unterstützt mehrere Sprachen, darunter Türkisch, Deutsch, Spanisch und Französisch. Gehen Sie einfach zu Agentenübersicht > Einstellungen (Zahnradsymbol) > Sprache und wählen Sie Ihre Muttersprache aus. Wenn Sie eine weitere Sprache hinzufügen möchten und dabei helfen können, melden Sie sich.

</p>
<p>
Circulo3 enthält außerdem einige Leistungsverbesserungen, die die App etwas schneller und zuverlässiger machen sollten.

</p>
<p>
Wenn Sie an der Diskussion und den Tests teilnehmen möchten, beantragen Sie die Mitgliedschaft im Circulo-Telegram-Kanal, indem Sie eine E-Mail mit dem Betreff „Ich möchte mitmachen!“ an info@unyt.co senden. Unser Team sendet Ihnen einen Einladungslink.


Für Version 3 von Circulo planen wir eine intensive Testphase.


Die Tests beginnen am Mittwoch, den 5. November. Wir bitten alle, Transaktionen zu senden, verschiedene Sprachen auszuprobieren und die App ein paar Tage lang zu erkunden.


Nach Freitag, dem 7. November, können Sie die App gerne weiterhin nutzen. Gehen Sie jedoch davon aus, dass die meisten (einschließlich unseres Teams) ihre Tests abgeschlossen haben und die App nicht mehr verwenden.


Suchen Sie sich Empfänger für CIRC in der <a href="https://docs.google.com/spreadsheets/d/1W-Ljs5lc6d4CjCTFKTYIoSxJr6ShJt26LZFvzyuHnbQ/edit?usp=sharing">Circulo3-Adressliste</a>.


</p>
<p>
Und <a href="https://forms.gle/F87ZVcX9avZEL985A">tragen Sie sich über dieses Formular ein</a>, damit auch andere Ihnen CIRC senden können.

</p>
<p>
Hinweis: Bitte stellen Sie sicher, dass Sie eine Adresse von Circulo 3 und nicht von einer älteren Circulo-Version verwenden.

</p>
<p>
Sollten Sie einen Fehler feststellen, melden Sie ihn bitte <a href="https://github.com/unytco/circulo-tx5/issues">als Problem</a> in diesem Repository (sofern er nicht bereits gemeldet wurde). Oder erwähnen Sie ihn zumindest im Circulo-Telegram-Kanal und verwenden Sie den Hashtag #issue.

</p>
<p>
So beheben Sie einen Fehler:

1. Warten: Eine Tasse Tee hilft oft.

2. Neu laden: Im Zweifelsfall: Rechtsklick > Neu laden (beachten Sie jedoch, dass wiederholtes Neuladen die Wartezeit verlängern kann, da jedes Mal alle Inhalte der Seite neu geladen werden).

3. Neustart: Wenn mehrere Neuladeversuche nicht helfen, beenden Sie die Anwendung und starten Sie sie neu.

</p>
<p>
Wir verwenden die Software Sentry, um Fehler zu erfassen und ihre Häufigkeit und ihren Kontext besser zu verstehen. Ihre Meldungen von Problemen sind aber ebenfalls sehr hilfreich.

</p>

## Installation

<details>
<summary><strong>Windows</strong></summary>

1. Laden Sie das `.msi`-Installationsprogramm herunter.

2. Führen Sie das Installationsprogramm aus und folgen Sie dem Installationsassistenten.
3. Starten Sie Circulo über das Startmenü. Menü

</details>

<details>
<summary><strong>macOS</strong></summary>

1. Laden Sie die .dmg-Datei herunter.
2. Öffnen Sie die DMG-Datei und ziehen Sie Circulo in Ihren Programme-Ordner.
3. Starten Sie die Anwendung über den Programme-Ordner (möglicherweise müssen Sie die Anwendung in den Systemeinstellungen unter „Sicherheit“ zulassen).

</details>

<details>
<summary><strong>Linux</strong></summary>

**AppImage (Empfohlen)**

1. Laden Sie die .AppImage-Datei herunter.
2. Machen Sie die Datei ausführbar: `chmod +x circulo_0.1.0_amd64.AppImage`
3. Führen Sie die Anwendung aus: `./circulo_0.1.0_amd64.AppImage`

**Debian/Ubuntu**

1. Laden Sie das .deb-Paket herunter.
2. Installieren Sie die Anwendung: `sudo dpkg -i` circulo_0.1.0_amd64.deb`
3. Ausführen: `circulo`

</details>
